# Гарантийный контроль — обновления

Здесь лежат только готовые версии программы для коллег (раздел **Releases**).
Программа сама проверяет эту страницу при запуске и предлагает обновиться.

Первая установка: скачайте `GarantiynyiKontrol.exe` из последнего выпуска,
положите в свою папку и переименуйте в `ГарантийныйКонтроль.exe`.
